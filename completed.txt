--- 1. TradingAgents review (TauricResearch/TradingAgents) — DONE 2026-06-26 ---
Goal: study how TradingAgents is designed, how our model differs, and what to
adopt.

TradingAgents design: LLM analyst team (Fundamentals/Sentiment/News/Technical)
-> Bull vs Bear researcher DEBATE (N rounds) -> Trader -> LLM risk team ->
Portfolio Manager. LangGraph, many LLM calls/ticker. Persistent memory at
~/.tradingagents/memory: realized return + alpha vs SPY reflected back into the
PM prompt each run.

How we differ (and why, deliberately):
- They use LLM agents per analyst; we use NUMERIC SignalProviders + ONE Claude
  call. Far cheaper in tokens (Todo item 2 warns about exactly this).
- They DEBATE risk with LLM personas; we use a DETERMINISTIC risk core the LLM
  cannot override. For real money this is a safety SUPERIORITY, not a gap — keep.
- Genuine gaps we adopted from them:
  [DONE] Technical analyst -> signals/technical.py (RSI/MACD/trend, yfinance, no
         key). Registered in signals/aggregator.py; SignalKind.TECHNICAL added;
         unit-tested in tests/test_technical.py (indicator math).
  [DONE] Bull/Bear debate value imported CHEAPLY: prompt now has Claude reason
         through the strongest bull AND bear case internally before setting
         conviction (no extra agents/calls). See decision/prompts.py.
  [DONE] Reflection/memory loop (their best idea; == Todo 3.1 signal attribution):
         attribution.py reconstructs closed round-trips from the ledger, scores
         each entry signal source by realized win-rate + avg P&L, and injects a
         terse "## Track record" block into the decision prompt (trusted, outside
         <market_data>). Ledger now stores entry_signals on buys + realized P&L on
         exits; the WATCHDOG also records its stops/takes/trails/flattens so
         attribution sees every close it controls. Known blind spot: exchange-side
         bracket auto-fills (no code observes them). Tests: tests/test_attribution.py.

Explicitly NOT adopting: LangGraph multi-call orchestration, LLM-debated risk
(would weaken the deterministic safety core), per-ticker multi-agent fan-out
(token cost).

--- A.1 Government-contracts signal — DONE 2026-06-28 ---
signals/govcontracts.py (SignalKind.GOVCONTRACTS). Reads the shared
live/govcontractsall feed (recent dated awards: Ticker/Date/action_date/Amount/
Agency/Description). BULLISH-ONLY (an award is good news; absence isn't bad) — a
saturating award-count lean (1-e^-n/6, discriminates 1..50+ awards) + a top-end
bump for large total $, capped +/-0.4 (size vs revenue unknown). 120d lookback,
Date->action_date fallback, defensive Amount parsing ($/commas/strings).
Registered in SignalAggregator; decision prompt teaches it as a hard-but-slow
revenue catalyst. Verified live (BAH $390M/50 awards ranks top; scores spread
0.23-0.40). Tests: tests/test_quiver_datasets.py. PR #6.
