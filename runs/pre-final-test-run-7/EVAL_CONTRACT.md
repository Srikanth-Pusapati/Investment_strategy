**Counted rules**
1. **Sample floor** (reported; drives the extension only): in-window **satellite** closed round trips N >= 24. Satellite = `action='sell'`, non-null `realized_pl`, `exit_reason` not in the system set **{hedge_unwind, core_defense, regime_trim, defensive_rotate, correction, beta_trim}** (the literals present in `investment_strategy/` at the run-7 merge; `tests/test_contract_handles.py` asserts each exists and the checker prints any unknown exit_reason it meets); system rows are printed on their own line and never in N. Additionally every sell row of the system-managed ETFs (`--system-symbols PSQ,QQQ` = HEDGE_ETF / CORE_ETF, whatever their `exit_reason` — a core stop or a hedge trail is still a system exit) is excluded from N and listed on the same line. Duplicate/phantom rows (qty <= 0; same symbol+qty+realized_pl+exit_reason within 4 h) are dropped and listed.
2. **Window expectancy** (counted once N >= 24): mean satellite `realized_pl` > 0 at 95% one-sided (t, df = N-1). Printed, not counted: bootstrap-95 CI, PF, median, **mean ex-top-3, top-3 share**, equity-only vs options-only split. No grade above B may be claimed on a window whose ex-top-3 mean is <= 0.
3. **Pooled expectancy (live-pilot bar only)**: pooled same-fingerprint satellite N >= 60, mean > 0 at 95% one-sided. Not required for a window PASS.
4. **Daily alpha**: OLS of book return on SPY return over all pairs including day 1. Always printed (alpha/day, SE, t, r2). Counted at >= 20 pairs: alpha point estimate > 0 (t printed, not thresholded).
5. **Beta** (counted at >= 5 pairs): mean stamped ex-ante `book_beta_spy` over all close rows within +/-0.2 of 1.0; AND at >= 20 pairs the realized OLS beta's 90% CI (beta +/- 1.645*SE, SE = sqrt(s2/sxx)) must overlap [0.8, 1.2]. Both always printed.
6. **Drawdown**: max drawdown of close-row equity > -5%. Worst session = min dEquity between consecutive close rows (broker `day_pl` printed beside it).
7. **Capture** (counted at >= 6 SPY up-days AND >= 6 SPY down-days over the same pairs as rule 4): up-capture > down-capture AND down-capture < 1.0. QQQ/IWM and beta-adjusted captures printed, not counted.
8. **Decision-sell validity**: zero **UNSANCTIONED** decision-sell losses below 0.5x the planned stop. A decision sell is sanctioned when its ledger row carries a non-empty `sell_events` list — the BASIS the frozen risk gate approved it on, read off the same cycle snapshot the gate used: the deterministic event tags (`SELL AUTHORITY: <sym> decision-sell allowed on event(s) name_falling:...`), or `gate_winner:+x.x%` (approved as a winner; the fill restatement can land it a few bp negative), or `stop_reached:...`; under `LLM_SELL_AUTHORITY=events_only` every other sub-stop decision sell is rejected, so an unsanctioned row means the gate that ran is not the one that was frozen — which is what this rule exists to catch. Sanctioned rows below 0.5x are printed and NOT counted. (Run-6 read NO-GO on one such row — INTC Sep 14 2026, -4.33% vs an 8.91% stop = 0.49x, approved on `name_falling:-5.6% today vs SPY -0.7%` — because v2 could not see the sanction; item A-5 stamps it on every decision-sell row.)

**Window verdict**: a counted rule that never reaches its qualification floor (rules 4/5 below 20 pairs, rule 7 below 6/6 days) is reported N/A and does not block PASS; PASS if every counted rule that reached its floor passes and rule 2 is decided; PENDING (UNDER-FLOOR) if every counted rule passes but N < 24 after the extension; FAIL if any counted rule fails; CONFOUNDED on any validity breach not disclosed-and-accepted in an amendment registered BEFORE the last close row.
